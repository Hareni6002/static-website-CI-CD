Static Website Hosting with CI/CD

End-to-end DevOps pipeline: automated build, version control, and deployment using GitHub Actions and a self-hosted runner.

● Live — Deployed via CI/CD Pipeline

Project Overview

This project demonstrates a complete CI/CD workflow for static website deployment. A local Ubuntu virtual machine hosts an Nginx web server, connected to a GitHub repository through a self-hosted GitHub Actions runner. Every code change pushed to the main branch is automatically deployed — no manual intervention required.

Architecture & Deployment Flow

Key Components

Virtualization

Ubuntu 26.04 VM on VirtualBox, configured with Bridged Networking for LAN accessibility.

Web Server

Nginx serving static content from /var/www/html, managed via systemd.

Version Control

Git + GitHub repository tracking all source changes with authenticated push access.

CI/CD Automation

GitHub Actions workflow triggered on push, executed by a self-hosted runner on the VM.
